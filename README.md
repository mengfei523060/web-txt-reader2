# 拾光阅读 · 简洁小说阅读站

一个零依赖的纯前端小说 TXT 阅读网站：宣纸质感、真实翻页、书签、书库。
无需构建、无需后端，所有数据保存在浏览器本地（IndexedDB + localStorage）。

## 运行

在本目录启动任意静态服务器即可（IndexedDB 建议走 http 源）：

```bash
cd txt-reader-n1
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

首次打开会自动放入一本示例书《云渡口的杂货铺》，可直接体验翻页与书签。

## 功能

- **书库**：导入 `.txt`（支持拖拽、批量导入），自动识别 UTF-8 / GBK 编码、
  书名、作者与章节，卡片显示进度条与阅读时间；支持搜索、删除。
- **翻页**：CSS 多栏 + Range 测量实现逐页排版，点击页面两侧 / ← → / 空格 /
  触屏滑动翻页，章节自动衔接；点击页面中部可隐藏工具栏沉浸阅读。
- **书签**：一键收藏当前页（B），抽屉中列出全部书签，点击跳转、可删除。
- **目录**：自动切分章节（第N章/回/节、楔子、番外、Chapter N…），
  识别不到章节时按约 3200 字自动分节。
- **进度**：自动记忆每本书所在章节、段落与百分比，下次打开续读。
- **设置**：字号、行距、宋体/黑体、宣纸/旧书/夜读三套主题，均自动保存。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| ← / ↑ / PageUp | 上一页 |
| → / ↓ / 空格 / PageDown | 下一页 |
| 点击页面中部 | 收起 / 展开工具栏 |
| T / B / S | 目录 / 书签 / 设置 |
| Esc | 关闭抽屉，再按返回书库 |

## 文件结构

```
index.html        页面结构（书库 + 阅读器 + 抽屉）
css/style.css     样式与三套主题
js/db.js          IndexedDB 存储层
js/parser.js      解码 / 章节切分 / 广告行清洗
js/demo.js        内置示例书
js/app.js         主逻辑（分页、书签、书库、设置）
```
